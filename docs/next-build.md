# Next build

Changes to the distribution wait here. They stay on this list until you say to build the next one.

When you say to build the next one, the waiting changes get made, committed, and pushed to main. Hammerite builds the AMD/Intel image, then the NVIDIA image. When each job finishes, the machine uploads that ISO to R2 on its own.

The 2026-10-25 night push ships Install WASD. The steps are User, Look, Apps & Agents, System, and Disk. System is the computer name and the network. On a live USB the last step erases only the selected disk. The first boot asks for a password only when that box was checked. The login default is `throne.jpg`. The lock screen uses that same picture. WASD Look can change the user picture.  The theme pack is in this tree. Completing the install downloads the checked Flatpaks on first boot, and the optional apps are out of the image lists. Brave stays installed and is the default browser. The ISO gets smaller when this tree is pushed.

This build puts Install WASD on the live desktop, on the desktop icon, and in the menu under that name. The old Install to Hard Drive shortcut is removed. The portal and the three-button dialog do not open. The Disk page can keep a second drive for games, or leave part of the only drive for games at a size they set. Completing the install downloads the checked Flatpaks on the first boot. Brave stays in the image.

## In this tree

`build_files/install-themes.py` installs the Plasma theme pack from the pins in `build_files/theme-pack.tsv` on both images. The default global theme is We10XOS-dark. The wallpaper stays stained-glass. The session splash stays the WASD W. Install WASD saves the loading picture, the login picture, the theme, and the wallpaper. The disk install writes that look for the new account. Completing the install applies it again on the first desktop, including the running session. The wallpaper stays the one they picked. The session splash stays the WASD W. Install WASD and WASD Look open through `/usr/bin/wasd-qml`, because the base image has the Qt libraries and does not have a `qml` command. When Windows is on a drive this install does not erase, `/usr/libexec/wasd-windows-boot` adds a Windows line to the WASD boot menu. The Windows drive is not rewritten.

4. System. The computer's name, and the network. The name box starts filled in with wasd, and the note above it says "Give your computer a name." They can change the name. It is not chosen at random.
