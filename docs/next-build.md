Take the optional apps out of the ISO. The live desktop opens one window, Install WASD, and no other popup. Closing that window leaves the live desktop usable. Warnings (legacy BIOS / CSM, low memory, another operating system already on a disk) sit at the top of that window. If the firmware is legacy BIOS, the window says to switch it to UEFI and the install stays unavailable. They can still close the window.

When nothing is blocking the install, the wizard steps are titled User, Look, Apps & Agents, System, and Disk. Disk is last.

1. User. Three things. The username. A row of character icons from `wasd-icons/`, which is the picture shown next to the name on the login screen. The WASD logo stays in that folder and is not one of the choices. One character starts selected. Clicking that same character again clears it, and the account keeps the ordinary user picture. Set a password, a checkbox that starts unchecked. While it is unchecked, the page says, in red, "Without a password, anyone who can turn on the computer is you." Under that, in cream: "Setting a password will secure the login screen, and an administrative command will ask for it. Not setting a password will not prompt for one." The computer signs in by itself. Checking it does not ask for the password on this page. You will choose it the first time this computer starts. That password is also the administrator password. There is no separate root account. `wasd-icons/`, `wasd-loading-screens/`, `wasd-login-screens/`, and `wasd-wallpapers/` are all copied onto the installed system, so the pictures are still there after install.
2. Look. Loading screen, login screen, and desktop, on this one step. Each starts closed, with a triangle and the current picture, so all three fit at once. Opening one shows its choices and closes the other two. The choices are the image files in a folder, so adding a picture adds a choice.
   - Loading screen, from `wasd-loading-screens/`. This is the Plymouth artwork. The bar along the bottom stays. The default is `stained-glass.jpg`, the close-up stained-glass W. The disk install writes the chosen picture and rebuilds the startup picture, so the first boot of the installed system already shows it. The key sketch stays in the folder as a choice. The USB menu is separate from that picture. It is black with white text and has no picture.
   - Login screen, from `wasd-login-screens/`. The default choice is `throne.jpg` in that folder. `camp.png` stays a choice.
   - Desktop. Global theme and wallpaper. We10XOS-dark is the default theme. Wallpapers come from `wasd-wallpapers/`. The default wallpaper is `stained-glass.jpg`, the room with the stained-glass W. `wasdsketch.png` stays a choice.
   The new loading and login folders start with the pictures already in the repo, so there is something to pick. The defaults are the ones named above.
3. Apps & Agents. Suggested apps and the agent list on one step. Apps starts open and Agents starts closed. Collapsing Apps opens Agents, and collapsing Agents opens Apps, so only one is open. The closed one shows what is already selected. Each open section has Select All and Select None. Select All checks that section's own list. On Apps it does not check every app a search might show. Select None clears that section, and on Apps it also clears anything added from search. The current WASD flatpak list, plus VLC, GIMP, and Bitwarden, checked by default. MakeMKV is not offered. Steam is not on this list. It is already part of the system. A search box adds any other Flathub app. Desktop apps stay Flatpak. The agents Omarchy ships, plus the Grok pieces, are listed here and installed when chosen, not baked into the ISO. Grok Build (`grok`), Grok Bot, and a Grok web app (grok.com opened as its own window, the same kind of web app Omarchy makes) start checked. The other agents start unchecked: Claude Code, Codex, OpenCode, Antigravity, Amp, Command Code, Copilot CLI, Crush, Cursor CLI, Devin, DeepSeek Harness, Freebuff, Hermes, Kilo, Kimi, Kiro, MiniMax Code, Muse, Oh My Pi, Ori, Pi, Qwen, and the desktop apps ChatGPT, Claude, Hermes Desktop, OpenClaw, Perplexity, T3 Code, LM Studio, and Ollama. Agents install the way Omarchy installs them.

4. System. The computer's name, and the network. The name box starts filled in with wasd, and the note above it says "Give your computer a name." They can change the name. It is not chosen at random. If a connection is already there, the page says it is connected. If not, it says "No connection detected, expand to configure." Expanding works either way. Wi-Fi lists the networks it found, or they type a network name and a passphrase. An empty passphrase is an open network. On the live USB the radio turns on only when they expand that section. TCP/IP is automatic, or a manual IP address, netmask, gateway, and DNS. Connect and Use these settings apply on the live USB through NetworkManager, so the computer is online before the later downloads. The passphrase and those addresses are not written into the choice file or the installer file. The saved connection is copied onto the installed system. In this preview the page says the computer was not changed. Next stays available with no connection. The wipe does not need a network.
5. Disk. This is the last step. The recommended install is one drive, and the page says so in plain text: the selected drive will be wiped. They pick the disk. It ends with the button "Erase the selected disk and install WASD". That erases the whole chosen disk. Other disks stay untouched unless they open Games drive and choose one. The installer is only allowed to touch the selected disk, so it cannot rewrite another operating system's boot files. A disk that already has an operating system is not selected by default. If they select it, the button names what will be erased. When another system is present, the page says this computer will start WASD afterward, and the other system is started from the computer's own boot menu. Warnings that need a person to do something are red. When Windows is present: turn off BitLocker and fast startup in Windows before installing. When the firmware is legacy: set it to UEFI in the BIOS, and the motherboard manual explains how. When Secure Boot is on, the next boot asks to enroll a key (choose Enroll MOK and enter `universalblue`). The selected drive says WARNING! This drive will be wiped. A line on the page says "A second drive for games can stay when you reinstall WASD." A Games drive section stays collapsed. Another drive with a Steam library, or a filesystem named games, can be used and is not erased. An empty drive can be formatted, named games, and mounted at /games. A drive that already has files, and is not Windows, can be used without erasing it. A Windows drive stays, and it is never the games drive. When the computer has only the one install drive, the section offers "Leave the rest of this drive for games." That choice starts off. Turning it on shows a slider and two boxes, in gigabytes, for WASD and for games. WASD keeps at least 64 GB and games keep at least 32 GB. The games space is a partition named games, mounted at /games. The recommended install is still one whole drive, wiped, with no split, until they turn that on. An Advanced section stays collapsed under the disk list. It opens the existing installer for partitioning and the other disk choices, including encryption. That is not the recommended install. Bazzite's live installer documents automatic wipe as the choice it offers. Manual partitioning is documented on the legacy ISO.

Install WASD is a new app, and so is the window on first boot. The window source is `wasd-install/`. Both are one Qt program, using the toolkit KDE already ships, and both are meant to look finished: the WASD logo, our colors, real type and spacing, and no stock dialog. The disk write is the existing installer run with no window of its own, from choices this app saves. On a live USB, the erase button wipes only the selected disk through the existing installer. Every other disk is left alone. The password and the Wi-Fi passphrase are not written into the installer file. The preview on this machine still saves the choices and does not erase anything. After the erase button there are no more choices. The username, the computer name, sign-in, and the saved network connection are written with the disk. The loading screen and the login screen are saved with those choices.

The first time the installed system reaches the desktop, a window titled "Completing the install" stays up while the work runs. It shows the logo, a circular animation, and one line for the current step: setting the desktop, installing what they checked, then "Finishing up". When the password box was checked, this window asks for it first. Two boxes, typed twice, and they have to match. There is no skip. Closing the window before the password is set brings it back on the next boot. After the password is set, automatic sign-in turns off for the next boot, and the same three lines run. When the box was left unchecked, the window skips the password and the computer keeps signing itself in. If the network is down, the desktop look still applies and the downloads wait in that same window. That window is `wasd-install/Complete.qml`. Opening it in this preview shows the password window and then the three lines. It does not set a password, change the login, install anything, or remove a startup entry. A separate welcome app is not in this preview. A new account gets `Welcome.txt` on its desktop from `/etc/skel/Desktop/Welcome.txt`. Plasma does not show desktop icons unless the desktop is set to show them, so the file is in the Desktop folder either way. The global theme stays in KDE's own settings.

WASD Look is installed with the system. The window is `wasd-install/Look.qml`. It matches the Look step and changes pictures: the loading screen, the login screen, the wallpaper, and the user picture. The user picture is the same ten characters. Clicking the selected one clears it. Theme chips stay out of this window. The wallpaper changes immediately. The user picture and the login screen change at the next login. The loading screen is rebuilt on that computer and shows up on the next boot. That rebuild is not a new ISO. Apply leaves the account picture alone unless a character was picked or cleared in that window. Opening WASD Look in this preview writes a choice file and does not change the computer. The picture folders are copied onto the installed system for that window.
