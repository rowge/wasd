WASD

About

The project

WASD is for playing games on a PC. It is a Linux desktop with Steam ready, and with the programs a gaming setup tends to need. Bazzite is the system underneath. Waydroid is left out, so this is not an Android setup. The desktop is KDE.

Steam and Brave are installed. Brave is the browser. Discord, OBS Studio, Heroic, Element, Bottles, and the tools for game audio, a mouse, lights, and the GPU are downloaded on the first boot when you leave them checked and the computer is online. VLC, GIMP, and Bitwarden are downloaded the same way.

WASD is available in two flavors. AMD and Intel is the one for most PCs. NVIDIA is the one for GeForce cards. Pick the one that matches the graphics card. The page How to make a bootable USB is how the file gets onto a stick.

I like photography. A lot of the wallpapers are photographs I took. The loading screens and the login screens are pictures made for WASD. Install WASD and WASD Look is where those pictures are chosen, and where a games drive is explained.

A Windows install on a second drive can stay. The PC starts WASD. The other system is started from the firmware boot menu. The games themselves can stay on their own drive, mounted at /games, and a later install of WASD can use that drive again.

Updates come as a new image of the whole system, the way Bazzite does it. Questions, bugs, and contributions go to GitHub. There is no support email.
