WASD

What's not supported, and how to help.

Some well-known games will not run here. The list below is the ones people ask about. It is not every game. This is the state of those games on Linux as of October 2026. It is not a test of one WASD computer.

What will not run

  • Valorant and League of Legends. They use Vanguard, and there is no version of it for this system.
  • Call of Duty and Warzone. They use Ricochet, and there is no version of it for this system.
  • Battlefield 6, and other EA games that use Javelin. That anti-cheat does not run here.
  • Fortnite. It uses Easy Anti-Cheat, and Epic has not turned the Linux mode on.
  • Apex Legends. It had Linux support, and EA turned it off in October 2024.
  • Rainbow Six Siege. It uses BattlEye, and Ubisoft has not turned that mode on.
  • Grand Theft Auto Online. It uses BattlEye, which Rockstar added in September 2024, and Rockstar has not turned that mode on.
  • Destiny 2. It uses BattlEye. Bungie says the game is not supported here. Trying to get around that check can close the account.
  • Red Dead Online. It is not reliable.
  • The EA App. It is currently known broken. I'll add it back as soon as I become aware that it is fixed.

No path at all

The game checks for its anti-cheat before it starts. When that check has no way to run here, the game does not start.

Valorant and League of Legends use Vanguard. It is a Windows driver that starts with Windows, before the game. There is no version of it for this system. Those games run here only if Riot ships a different anti-cheat.

Call of Duty and Warzone use Ricochet. It is the same kind of Windows driver. There is no version of it for this system.

Battlefield 6, and other EA games that use Javelin, use a Windows kernel anti-cheat. It does not run here.

The studio can turn it on

Easy Anti-Cheat and BattlEye are also Windows drivers. Each one also has a separate mode for Proton. Proton is the part of this system that runs a Windows game. That mode is not the Windows driver running on Linux. The studio that publishes the game is the one that turns it on.

Elden Ring and Rust have it on. Those games can run.

Fortnite uses Easy Anti-Cheat, and Epic has not turned that mode on. Apex Legends had Linux support, and EA turned it off in October 2024. Rainbow Six Siege uses BattlEye, and Ubisoft has not turned that mode on. Grand Theft Auto Online uses BattlEye, which Rockstar added in September 2024, and Rockstar has not turned that mode on. Destiny 2 uses BattlEye. Bungie says the game is not supported here. Trying to get around that check can close the account.

The EA App

The EA App is currently known broken. Its installer does not finish, so WASD does not set it up. I'll add it back as soon as I become aware that it is fixed.

Games from EA need that app. That includes a game with no anti-cheat. Until the app works, those games are not part of WASD. Apex Legends, EA Sports FC online, and Battlefield 6 online also use anti-cheat that does not run here.

Games from Ubisoft and Rockstar

Ubisoft Connect and the Rockstar Launcher do open. A game you play on your own from those stores is the kind that usually runs. The Assassin's Creed and Far Cry stories, the Grand Theft Auto V story, and the Red Dead Redemption 2 story are in that group.

An online game from the same store can still refuse to start. Rainbow Six Siege and Grand Theft Auto Online are in that group. Red Dead Online is not reliable. The single-player story of Grand Theft Auto can still be played. The online mode cannot.

Here's what you can do to help

Contact the studios and tell them you demand Linux support. A polite note is the one a studio can pass along. You can send this. Put the game's name in the first lines.

Hello,

I play on Linux. I would like to play your game there.

The game does not start, because of its anti-cheat. Easy Anti-Cheat and BattlEye can allow Linux when the studio turns that on for the game. A Windows-only anti-cheat needs a version that runs on Linux.

I want to buy the game and play it fairly, with everyone else. Thank you for considering it.

Most of these forms ask you to sign in. That is the studio's own page.
