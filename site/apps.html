WASD

Install WASD and WASD Look

Install WASD runs from the USB you already created and writes the system to a drive. WASD Look changes the loading screen, the login screen, or the desktop after install. The first boot opens a short window, Completing the install.

This applies to the install. Turn off BitLocker and fast startup in Windows before you install. A locked or hibernated Windows volume can get in the way even when you are installing to a different drive. If the firmware is legacy BIOS, set it to UEFI. The motherboard manual explains how, and the install stays unavailable until then. If Secure Boot is on, the next boot asks you to enroll a key. Choose Enroll MOK and enter universalblue.

None of this applies to the live session.

Install WASD

Boot the USB and choose Start WASD. If you have graphics issues booting, you can try Start WASD (basic graphics). The live desktop opens Install WASD. You can close the window and keep using the desktop. Open it again from the desktop icon or the menu. Both are named Install WASD.

The steps are User, Look, Apps, System, and Disk. Disk is last. That step erases a drive.

User

Set a password is unchecked. Leave it unchecked and the computer signs itself in. Administrative prompts are accepted with Enter. Check it, and the password is typed the first time the installed computer starts, in two boxes that have to match. There is no skip. That password is also the administrator password. There is no separate root account, and the password is not stored in the installer file.

Look

Loading screen is the picture behind the bar while the computer starts. Login/lock screen is the sign-in picture and the lock screen. Desktop wallpaper is the picture on the desktop. The global theme is We10XOS-dark. System Settings changes that theme. The defaults are the stained-glass loading picture, the throne login picture, and the stained-glass desktop.

The choices are saved with the install. A new system already uses those three defaults. WASD Look changes them after install. Adding a picture file to the matching folder adds a choice:

Loading screens: /usr/share/wasd/loading

Login screens: /usr/share/wasd/login

Wallpapers: /usr/share/wallpapers/wasd

Those folders belong to the system, so copying a file into one asks for the administrator password.

Apps

Steam and the Brave browser are included. Apps selected here are downloaded after the first boot.

The agents are coding and chat tools. They are saved with your choices and installed on the first boot. Grok opens in its own Brave window. The others that are web apps do the same.

System

The saved name is lowercase. Letters, numbers, and hyphens are allowed.

A connection that is already up is named here. Wired looks like "Connected. Wired." Otherwise the line is "No connection detected, expand to configure."

Choose a Wi-Fi network if you want one. The passphrase is asked on the first boot, and it is not saved in the installer file. You can also set an address, a netmask, a gateway, and DNS. That is saved with the adapter you choose, including an adapter that is down.

Disk

Click a drive to select it. The install button erases that drive and asks once if you are sure. No cancels. Yes installs it.

A Windows drive says "WARNING! This erases Windows." and the button says Erase Windows and install WASD. Any other drive says "WARNING! This drive will be wiped." and the button says Erase the selected disk and install WASD. On a Windows drive the question is titled "This erases Windows."

Turn off BitLocker and fast startup in Windows before you install. A locked or hibernated Windows volume can get in the way even when you are installing to a different drive. If the firmware is legacy BIOS, set it to UEFI. The motherboard manual explains how, and the install stays unavailable until then. If Secure Boot is on, the next boot asks you to enroll a key. Choose Enroll MOK and enter universalblue.

After the install, the PC starts WASD. Windows on another drive is on the WASD boot menu. Any other system is started from the firmware boot menu. WASD does not rewrite another system's boot files.

Advanced stays closed. It holds the existing installer's partitioning and disk choices, including encryption. Install WASD does not open it.

A drive for games

Set up /games lets you select an existing drive with games already installed, wipe and use a second drive for games, or you can create a persistent partition for games that will survive a reinstall of WASD without having to re-download games if you only have one drive (recommended).

Another drive

With more than one drive, Set up /games lists the other drives and the drive selected for WASD. Choose another drive and the window asks once if you are sure. No cancels. Yes applies it.

A drive with a Steam library, or a filesystem named games, is mounted at /games and is not erased. A Steam library is a steamapps folder, or SteamLibrary/steamapps. The name games can be any capitalization. A library on NTFS is mounted. It is not formatted.

An empty drive is formatted as btrfs, named games, and mounted at /games. A SteamLibrary folder is created.

A drive that already has files can be mounted without erasing them. The files stay in their folders.

A Windows drive can be used for /games when BitLocker is off. The question says Windows is on the drive, and that the files stay. If BitLocker is still on, that drive cannot be used for /games until it is turned off.

On the WASD drive

With one drive, Set up /games shows a slider. With more than one, choose the WASD drive in that list and the same slider appears. Click Set up /games again on a single drive, or click the WASD drive again, to leave the whole drive for WASD.

The slider and the two boxes are in gigabytes. WASD keeps at least 64 GB. /games keeps at least 32 GB. About 4 GB is held for the boot partitions, so a drive that cannot hold both is not split. The slider starts at 128 GB for WASD, or less when the drive is smaller, and the rest goes to games. You can type either number. WASD uses the first part of the drive. The rest is its own partition, named games, mounted at /games.

A split and a separate games drive are not used together. Choosing one turns the other off.

Where the games are

The path is /games. In Steam, add a library folder at /games/SteamLibrary for new games. An existing library stays in its old folder.

The next install recognizes a drive named games, or a drive with a Steam library. It is still your choice. A games drive from Windows will not be named games. A Steam library on it is enough. If the drive is only files, choose it yourself. That choice keeps the files.

The first boot

The default artwork is still shown on this boot, and it will update to your selections on the next boot.

If you checked Set a password, that comes first. Two boxes, and they have to match. There is no skip. The window says this password is also the administrator password, and that the next boot asks for it. That boot shows the login window with the character picture, the username, and a password box. The background is the login picture. Clearing the character leaves the ordinary user picture. Automatic sign-in turns off for the following boot. The session you are in stays signed in. Closing the window before the password is set brings it back the next time the computer starts.

If you chose a Wi-Fi network, that comes next. When no password was asked for, it comes first. The line says Connect to, and then the saved name. Leave the box empty when the network is open. Connect joins it. Cancel warns that the selected applications will not be installed without a connection. Go back returns to the passphrase. Continue goes on without that network. A wrong passphrase stays on this step. Closing the window before you connect or continue brings it back. When no network was saved, this step is skipped. The passphrase is not stored in the installer file.

The desktop icon is named Completing the install. Closing the window leaves it. When the window finishes, the icon moves to the trash and is taken off the list of programs that start at login.

The lines are "Setting the desktop.", then "Installing the agents." when any were checked, then "Installing what you checked.", and "Finishing up." A saved Ethernet address is applied when those lines start. If the adapter is not connected yet, the window says the address was saved. A Wi-Fi address is used when that network connects. Skipping Wi-Fi does not create a Wi-Fi connection.

On "Installing what you checked." the selected apps are downloaded. Steam and Brave are already installed. If the computer is offline, the window stops and lets you choose a Wi-Fi network or set an address, a netmask, a gateway, and DNS. The passphrase is typed there and is not saved. You can skip that prompt. The window can still finish, and Discover can add an app later. Closing the window instead of skipping leaves the desktop icon.

If one app fails, the window names it. Retry tries again. Continue leaves that one out and goes on. When OBS Studio is selected, its capture plugins are downloaded with it.

"Setting the desktop." applies We10XOS-dark, the loading picture, the login picture, and the wallpaper. The lock screen uses that same login picture. The session splash stays the WASD mark. System Settings changes the theme later. Retry tries the look again. That step does not offer Continue.

When agents were checked, "Installing the agents." installs them one at a time. Grok, and the other checked web apps, open in their own Brave window. Command-line agents that have an installer are downloaded here. Retry tries again. Continue leaves that one out, and its menu entry stays. Sign-in uses your own account. WASD Look can still change the pictures later.

To sign in automatically again after a password is set, open System Settings, then Security and Privacy, then Login Screen, and turn on Automatically log in.

WASD Look

Open WASD Look from the menu after the system is installed. It uses the same folders. Loading screens are /usr/share/wasd/loading. Login screens are /usr/share/wasd/login. Wallpapers are /usr/share/wallpapers/wasd. The user picture is the same ten characters. Click the selected character again to clear it. Apply leaves the account picture alone unless you picked one or cleared it on that visit.

The wallpaper changes immediately. The user picture and the login/lock screen change at the next login. The lock screen uses that same picture, and it changes the next time the screen locks. The loading screen is rebuilt on that computer and shows on the next boot. That rebuild is not a new download of WASD. Theme choices stay in KDE's own settings.

WASD Launchers

Open WASD Launchers from the menu. The rows are Battle.net, the EA App, Ubisoft Connect, the Rockstar Launcher, and Minecraft. Type a name and press + for a program you already downloaded. WASD makes a folder for it. During install, those launchers are the Launchers group under Apps. That group starts closed, and nothing in it is checked.

Minecraft keeps its games and worlds in /games/minecraft. Pressing + makes /games/custom1, then /games/custom2, and so on. Install then opens the program you downloaded. Drive D: in that window is that folder.

Nuke/Fix rebuilds that launcher only. Saved games stay.

The stick is covered in How to make a bootable USB.
