WASD

The Apps: Install, Look, and Launchers

A hardcore build gets each update as it is published. The normal download gets those changes after they have been checked. Back to the downloads.

WASD Install runs from the USB you already created. WASD Look changes the pictures after install. The first boot opens Completing the install.

Do this in Windows before you install. None of it applies to the live session.

  1. Turn off BitLocker and fast startup.

    A locked or hibernated Windows volume can get in the way even when you install to a different drive.

  2. If the firmware is legacy BIOS, set it to UEFI.

    The motherboard manual explains how. The install stays unavailable until then.

  3. If Secure Boot is on, enroll the key on the blue screen.

    The password is universalblue.

WASD Install

  1. Boot the USB and choose Start WASD.

    If the picture fails while starting, choose Start WASD (basic graphics).

    The desktop opens WASD Install. You can close it. Open it again from the desktop icon or the menu.

  2. Go through User, Look, Apps, System, and Disk.

    Disk is last. That step erases a drive.

User

  1. Type a name and leave the character, or click it again to clear it.

    One character starts selected. Clearing it keeps the ordinary user picture.

  2. Leave Set a password unchecked if the computer should sign itself in.

    Administrative prompts are accepted with Enter.

    Completing the install then creates an encryption key without asking. Proton Mail and other apps use it to store a secret. The key has no passphrase, and it is not a lock. Anyone at the computer can open it.

  3. Check the box if you want a password.

    You type it the first time the installed computer starts, in two boxes that have to match. There is no skip. It is also the administrator password. There is no separate root account, and it is not stored in the installer file. The key above is not created.

Look

  1. Open a row and pick a picture.

    Loading screen is the picture behind the bar while the computer starts and while it shuts down. Those are two copies. Startup uses the copy in the startup image, so a new choice shows the next time the computer starts. Shutdown uses the picture WASD Install and WASD Look saved, so that copy changes when the picture is saved.

    Login/lock screen is the sign-in picture and the lock screen. Desktop wallpaper is the picture on the desktop. The theme is We10XOS-dark. System Settings changes that theme.

    The defaults are the stained-glass loading picture, the throne login picture, and the stained-glass desktop. A new system already uses them. The choices are saved with the install. WASD Look changes them later.

  2. To add a picture, copy the file into that folder.

    Loading screens
/usr/share/wasd/loading

Login screens
/usr/share/wasd/login

Wallpapers
/usr/share/wallpapers/wasd

    Those folders belong to the system, so copying a file in asks for the administrator password.

Apps

  1. Leave the suggested apps checked, or turn off the ones you don't want.

    Steam and Brave are already included. Apps you leave checked are downloaded after the first boot.

    A closed row shows what is selected. Select All and Select None apply to the open list. Search adds a Flathub desktop app, and Select All does not check those results.

  2. Open Agents if you want a coding or chat tool.

    Agents starts closed. Grok Build, Grok Bot, and Grok start checked. They are installed on the first boot. Grok opens in its own Brave window, and the other web apps do the same.

System

  1. Name the computer, or leave it as wasd.

    The note says "Give your computer a name." The saved name is lowercase. Letters, numbers, and hyphens are allowed.

  2. Use the connection that is already up, or pick a Wi-Fi network.

    A wired connection looks like "Connected. Wired." Otherwise the line is "No connection detected, expand to configure."

    The Wi-Fi passphrase is asked on the first boot, and it is not saved in the installer file. You can also set an address, a netmask, a gateway, and DNS. That is saved with the adapter you choose, including an adapter that is down.

Disk

  1. Click the drive WASD should use.

  2. Choose the install button, then Yes.

    No cancels. It asks once.

    A Windows drive says "WARNING! This erases Windows." The button says Erase Windows and install WASD, and the question is titled "This erases Windows." Any other drive says "WARNING! This drive will be wiped." The button says Erase the selected disk and install WASD.

    Turn off BitLocker and fast startup first. A locked or hibernated Windows volume can get in the way even on a different drive. Legacy BIOS has to be set to UEFI, or the install stays unavailable. If Secure Boot is on, the next boot stops on a blue screen. Enroll the key there. The password is universalblue.

    Afterward the PC starts WASD. Windows on another drive is on the WASD boot menu. Any other system starts from the firmware boot menu. WASD does not rewrite another system's boot files.

    Advanced stays closed. It holds the existing installer's partitioning and disk choices, including encryption. WASD Install does not open it.

A drive for games

  1. Choose Set up /games if games should survive a reinstall.

    You can keep a drive that already has games, wipe a second drive for games, or split the only drive so the games partition stays when WASD is installed again. Splitting the only drive is the recommended way to avoid downloading games again.

Another drive

  1. Choose the other drive, then Yes.

    Set up /games lists the other drives and the drive selected for WASD. No cancels. It asks once. When the drive is kept, the question says WASD will use this drive and will NOT wipe it.

    The install button then names both drives. Keeping the games drive, it says Erase WD Black 1TB and use WD Black 2TB for /games. The first drive is erased. The games drive is not. When that drive is formatted, the button says wipe, as in Erase WD Black 1TB and wipe WD Black 2TB for /games. The names and sizes are the drives you picked.

    A drive with a Steam library, or a filesystem named games, is mounted at /games and is not erased. A Steam library is a steamapps folder, or SteamLibrary/steamapps. The name games can be any capitalization. A library on NTFS is mounted, not formatted.

    An empty drive is formatted as btrfs, named games, and mounted at /games. A SteamLibrary folder is created. A drive that already has files can be mounted without erasing them.

    A Windows drive can be used for games when BitLocker is off. The question says Windows is on the drive, and that the files stay. If BitLocker is still on, that drive cannot be used until it is turned off.

On the WASD drive

  1. Open the slider and set the two sizes.

    With one drive, Set up /games shows the slider. With more than one, choose the WASD drive in that list. Click Set up /games again on a single drive, or click the WASD drive again, to leave the whole drive for WASD.

    The slider and the two boxes are in gigabytes. WASD keeps at least 64 GB. Games keep at least 32 GB. About 4 GB is held for the boot partitions, so a drive that cannot hold both is not split. The slider starts at 128 GB for WASD, or less when the drive is smaller, and the rest goes to games. You can type either number. WASD uses the first part of the drive. The rest is its own partition, named games, mounted at /games.

    A split and a separate games drive are not used together. Choosing one turns the other off.

Where the games are

  1. In Steam, add a library folder at /games/SteamLibrary.

    That is for new games. An existing library stays in its old folder. The games drive itself is /games.

    The next install recognizes a drive named games, or a drive with a Steam library. It is still your choice. A games drive from Windows will not be named games. A Steam library on it is enough. If the drive is only files, choose it yourself. That choice keeps the files.

The first boot

  1. Let this boot finish. The picture you chose shows the next time the computer starts.

    This boot still uses the default picture while it starts. Shutting down uses the picture you chose.

  2. If you checked Set a password, type it twice.

    The boxes have to match. There is no skip. The window says this password is also the administrator password, and that the next boot asks for it. That boot shows the login window with the character picture, the username, and a password box. The background is the login picture. Clearing the character leaves the ordinary user picture.

    Automatic sign-in turns off for the following boot. The session you are in stays signed in. Closing the window before the password is set brings it back the next time the computer starts.

    If you left the box unchecked, this window creates the encryption key and a wallet that opens with the desktop. It does not ask. Checking the box skips that key.

  3. If you chose a Wi-Fi network, type its passphrase and choose Connect.

    This comes after the password. When no password was asked for, it comes first. The line says Connect to, and then the saved name. Leave the box empty when the network is open.

    Cancel warns that the selected applications will not be installed without a connection. Go back returns to the passphrase. Continue goes on without that network. A wrong passphrase stays on this step. Closing the window before you connect or continue brings it back. When no network was saved, this step is skipped. The passphrase is not stored in the installer file.

  4. Leave Completing the install open until it finishes.

    The desktop icon has that name. Closing the window leaves it. When the window finishes, the icon moves to the trash and is taken off the list of programs that start at login.

    The lines are "Setting the desktop.", then "Installing the agents." when any were checked, then "Installing what you checked.", and "Finishing up." A saved Ethernet address is applied when those lines start. If the adapter is not connected yet, the window says the address was saved. A Wi-Fi address is used when that network connects. Skipping Wi-Fi does not create a Wi-Fi connection.

  5. If the computer is offline, connect or skip when it asks.

    On "Installing what you checked." the selected apps are downloaded. Steam and Brave are already installed. The window lets you choose a Wi-Fi network or set an address, a netmask, a gateway, and DNS. The passphrase is typed there and is not saved. You can skip. The window can still finish, and Discover can add an app later. Closing the window instead of skipping leaves the desktop icon.

    If one app fails, the window names it. Retry tries again. Continue leaves that one out and goes on. When OBS Studio is selected, its capture plugins are downloaded with it.

  6. If "Setting the desktop." fails, choose Retry.

    That line applies We10XOS-dark, the loading picture, the login picture, and the wallpaper. The lock screen uses that same login picture. The session splash stays the WASD mark. System Settings changes the theme later. That step does not offer Continue. WASD Look can still change the pictures later.

  7. If an agent fails, choose Retry or Continue.

    "Installing the agents." installs them one at a time. Grok, and the other checked web apps, open in their own Brave window. Command-line agents that have an installer are downloaded here. Continue leaves that one out, and its menu entry stays. Sign-in uses your own account.

  8. To sign in automatically again, turn on Automatically log in.

    Open System Settings, then Security and Privacy, then Login Screen. This is only after a password is set.

WASD Look

  1. Open WASD Look from the menu.

    It matches the Look step, and it adds the user picture. The user picture is the same ten characters. Click the selected character again to clear it.

  2. Pick the pictures, then choose Apply.

    Loading screens
/usr/share/wasd/loading

Login screens
/usr/share/wasd/login

Wallpapers
/usr/share/wallpapers/wasd

    Copy a file into the matching folder to add a choice. Those folders belong to the system, so that copy asks for the administrator password.

    Apply leaves the account picture alone unless you picked one or cleared it on that visit. The wallpaper changes immediately. The user picture and the login/lock screen change at the next login. The lock screen uses that same picture, and it changes the next time the screen locks. Shutdown changes when you apply it. Startup is rebuilt on this computer and shows the next time it starts. That rebuild is not a new download of WASD. Theme choices stay in KDE's own settings.

WASD Launchers

  1. Open WASD Launchers from the menu.

    Each launcher is its own row: Battle.net, the Rockstar Launcher, Epic Games, Ubisoft Connect, Star Citizen, Minecraft Java, Minecraft Bedrock, FTB (modded Minecraft), PolyMC (modded Minecraft), MultiMC (modded Minecraft), and CurseForge (modded Minecraft). During install, those rows are the Launchers group under Apps. That group starts closed, and nothing in it is checked.

  2. Choose Install, then finish that launcher's own window.

    Launch opens one that is already installed. Each row has Nuke/Fix, Install, Launch, and Browse until it is set up. Browse opens that launcher's games folder.

    On Battle.net, the Rockstar Launcher, Epic Games, Ubisoft Connect, Star Citizen, and Minecraft Java, Install then says Reinstall. Reinstall runs that company's installer again and leaves the launcher where it is. Minecraft Bedrock, FTB (modded Minecraft), PolyMC (modded Minecraft), MultiMC (modded Minecraft), CurseForge (modded Minecraft), and a program added with + do not show Reinstall. Launch opens the program that is already there.

    Sign in inside the RSI Launcher and install the game there. Click No on the two errors that ask if you want to see more information. The launcher still works.

    Type a name and press + for a program you already downloaded. WASD makes /games/custom1, then /games/custom2, and so on. Install then opens that program. Drive D: in that window is that folder.

    Epic Games keeps its games in /games/epic. Star Citizen keeps its files in /games/starcitizen. Minecraft Java keeps its worlds in /games/minecraft. Minecraft Bedrock keeps its worlds and its download in /games/minecraft-bedrock. FTB (modded Minecraft) keeps its packs in /games/ftb. PolyMC (modded Minecraft) keeps its instances in /games/minecraft-modded. MultiMC (modded Minecraft) keeps its instances in /games/multimc. CurseForge (modded Minecraft) keeps its mod folder in /games/curseforge. Each launcher is pointed at that folder, so the games stay there.

  3. Use Nuke/Fix only to rebuild the launcher.

    It deletes that launcher's own folder, keeps the games, and opens it again. Saved games stay. It does not update the launcher.

  4. Let the launcher update itself.

    Battle.net, the Rockstar Launcher, Epic Games, Ubisoft Connect, Minecraft Java, and the RSI Launcher update themselves. When FTB (modded Minecraft), PolyMC (modded Minecraft), or CurseForge (modded Minecraft) asks to update, say yes. That is the launcher's own updater. MultiMC (modded Minecraft) updates when WASD's copy of it is updated.

    PolyMC (modded Minecraft) and MultiMC (modded Minecraft) keep Java 21, Java 17, and Java 8. A pack is given the Java version it asks for. Minecraft 1.16 and earlier use Java 8. Minecraft 1.17 through 1.20.4 use Java 17. Newer packs use Java 21. A Java you pick in that instance's settings stays as you set it. MultiMC (modded Minecraft) gives a pack 8 GB of memory when the pack is still on the 1 GB default.

The stick is covered in How to make a bootable USB.
