WASD

Linux for the gaming PC.

Boot a USB stick and the live desktop is already there. Install it when you want that same system on the disk.

NVIDIA

Open driver, for newer GeForce cards.

AMD and Intel

Mesa, for Radeon and Intel graphics.

  1. Write the image to a USB stick.
  2. Boot that stick. The menu says Start WASD.
  3. You are player on a computer named wasd.

The USB files are not on this page yet. Each one is several gigabytes, and they will be linked here when there is a public download.
