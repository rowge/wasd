Being tested on hardcore

These changes are on the hardcore download. They are being tested there. The normal download does not have them yet.

The big change is emulators. WASD Install has an Emulators section above Launchers. RetroArch, Dolphin, PCSX2, and RPCS3 start checked. They download on the first boot. They are not on the disc. The Games menu puts them in Emulators. Dolphin's name there is Dolphin Emulator. The games and the console firmware are files you already have. Each emulator can read /games, Documents, Downloads, and a drive plugged into the computer. Saves stay with that emulator. RetroArch downloads its own emulator cores. There is no store for the console games. PCSX2 and RPCS3 are large downloads.

WASD Install has a Games section above that. itch.io, 0 A.D., OpenTTD, SuperTuxKart, Luanti, Battle for Wesnoth, and Freeciv start checked. They download on the first boot. They are not on the disc. Luanti is the current name of Minetest. Freeciv's menu name is Freeciv SDL2 client. The Games menu puts them in Real Games.

Browser games is a folder in the Games menu. Kitten Cannon, Line Rider, QWOP, and Starship are in it. Each one opens in the browser.

WASD Launchers has Spawn. The hardcore image includes it, and a click opens it. Games stay on Spawn's servers.

Hardcore installs the font Anton. A page that asks for Impact or Impact Condensed gets Anton. The font's own name stays Anton.
