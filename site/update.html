WASD

How to update

WASD checks for an update about once a day and downloads it in the background. Restart the computer to finish it. Games and files stay.

To update now, open the menu and choose WASD Updater. The same window opens from this command:

wasd-updater

A hardcore install gets each update as it is published. The normal download gets those changes after they have been checked.

The previous system stays on the boot menu. If an update causes trouble, start the one from before.
