How to make a bootable USB

  1. Download the ISO for your graphics card.

    NVIDIA if you have a GeForce card. AMD and Intel if not.

    Hardcore gets every update as it is published. That disc is AMD and Intel or NVIDIA. In the commands below, use WASD-hardcore.iso or WASD-nvidia-hardcore.iso.

  2. Check the file against its checksum.

    AMD and Intel checksum NVIDIA checksum AMD and Intel hardcore NVIDIA hardcore

    On Linux, in the folder with both files:

    sha256sum -c WASD.iso.sha256

    On macOS:

    shasum -a 256 -c WASD.iso.sha256

    On Windows, compare the result with the text in the checksum file:

    certutil -hashfile WASD.iso SHA256

    For the NVIDIA disc, use WASD-nvidia.iso in those commands.

  3. Write it to a 16 GB or larger stick.

    Use a free tool for the computer you are on. It will erase the stick.

    On Windows, Fedora Media Writer or Rufus. In Rufus, write the ISO in DD mode.

    On a Mac, Fedora Media Writer or balenaEtcher.

    On Linux, Fedora Media Writer or balenaEtcher.

  4. Restart, open the boot menu, and choose the USB stick.

    The menu on the stick says Start WASD.
