How to make a bootable USB

Download the ISO for NVIDIA if you have a GeForce card, or AMD and Intel if not.

Check the file

When the download finishes, compare it with the checksum published next to it.

AMD and Intel checksum NVIDIA checksum

On Linux, in the folder with both files:

sha256sum -c WASD.iso.sha256

On macOS:

shasum -a 256 -c WASD.iso.sha256

On Windows, compare the result with the text in the checksum file:

certutil -hashfile WASD.iso SHA256

For the NVIDIA disc, use WASD-nvidia.iso in those commands.

Write it to a USB stick

Use a 16 GB or larger stick.

Use a free tool for the computer you are on. It will erase the stick.

Windows

Fedora Media Writer or Rufus. In Rufus, write the ISO in DD mode.

Mac

Fedora Media Writer or balenaEtcher.

Linux

Fedora Media Writer or balenaEtcher.

Boot it

Restart the PC, open the boot menu, and choose the USB stick. The menu on the stick says Start WASD.
